# FOODSAFE

HACCP 인증, 행정처분, 검사 부적합, 회수 데이터를 근거로 식품안전 관리자가 우선 확인할 영역을 탐색하는 Streamlit 프로토타입입니다.

## 주요 화면

- **종합 현황**: HACCP·사건 기록·우선 확인 후보의 실제 집계와 연도별 추이
- **단일 탐색 메뉴**: 중복된 2단계 분류 없이 핵심 화면으로 바로 이동
- **인증 생애주기**: 52,793개 인증의 지정·종료·폐업·반납 기록과 종료일 기준 상태
- **검사 → 회수 연결**: `RTRVLDSUSE_SEQ`로 직접 연결된 40개 사건의 Sankey와 근거표
- **지역·지도 분석**: `appointno`로 정확 연결된 HACCP 인증의 시도·시군구 드릴다운과 좌표 지도
- **검사·부적합 / 회수 분석**: 기간·지역·품목·검사 항목 필터, 사건 분포와 다운로드
- **행정처분 분석**: 유형·업종·연도·지역·법령·처분기간 분석
- **업체 통합 조회**: 정확한 허가번호로 연결된 인증·검사·회수·행정처분 이력
- **우선 확인 후보**: `LCNS_NO`로 실제 연결된 후보와 Why? 근거 확인
- **데이터 품질**: 결측·식별키·좌표·중복·정확 연결률 시각화
- **데이터·분석 방법**: 연결 기준, 해석 한계, 현재 보유 및 추가 필요 데이터 공개

핵심 분석 화면에는 `이 화면 읽는 법`을 제공합니다. 업체 통합 조회는 상호 일부와 허가번호 검색을 모두 지원하며, 필터 결과가 비어 있으면 차트 대신 조정 안내를 표시합니다.

각 핵심 화면은 `화면 목적 → 필터 → 핵심 지표 → 대표 시각화 → 해석 → 상세 기록·다운로드`의 흐름을 따릅니다. 상세표의 컬럼명은 사용자용 한글로 표시되지만, 다운로드 파일은 재현성을 위해 원본 컬럼명을 유지합니다.

생산규모, CCP, 개선·후속관리는 현재 검증 가능한 데이터가 없다는 사실을 명확히 안내하며, 가공한 수치나 위험 점수를 만들지 않습니다.

## 실행

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

배포본은 `processed/`의 전처리 데이터를 우선 사용하므로 원본이 없는 환경에서도 실행됩니다. 원본을 다시 전처리할 때만 환경변수 `FOODSAFE_DATA_DIR`에 원본 폴더 경로를 설정합니다.

## 전처리

```powershell
python analysis\preprocess.py
```

실행하면 `processed/`에 날짜·시도·시군구 보조변수, 완전 중복 제거 결과, 품질 요약, `record_linkage_audit.csv`가 저장됩니다. 원본 파일을 수정하거나 임의 위험점수를 생성하지 않습니다.

전처리 후에는 다음 명령으로 필수 파일, 행 수, 중복, 복합키, 정확 연결 건수를 검증합니다.

```powershell
python analysis\validate_outputs.py
```

`data_quality_manifest.json`에는 전처리 파이프라인 버전과 원본 파일별 SHA-256·크기가 기록됩니다. `data_catalog.csv`는 원본·정제 파일, 핵심 키, 행 수, 연결 정책을 요약합니다.

## 자동 테스트

```powershell
python -m unittest discover -s tests -v
```

자동 테스트는 최종 메뉴 11개, 허가번호 업체 조회, 검색 실패 처리, 빈 필터 결과, 핵심 집계값, 식별키 고유성, 원본 파일 지문을 검증합니다.

## 원본 데이터와 결합 원칙

| 역할 | 기준 파일 | 핵심 키 |
|---|---|---|
| 식품 HACCP 인증 | `20260914_114125.csv` | `LCNS_NO`, `HACCP_APPN_NO` |
| 축산물 HACCP 인증 | `20260916_100445.csv` | `LCNS_NO`, `HACCP_APPN_NO` |
| 행정처분 | `식품검사 부적합 이력 + 개선 시정조치, 후속관리.csv` | `DSPSDTLS_SEQ`, `LCNS_NO` |
| 부적합 검사 | `20260914_044911.csv` | `RTRVLDSUSE_SEQ`, 일부 `LCNS_NO` |
| 회수 | `20260914_045015.csv` | `RTRVLDSUSE_SEQ`, 일부 `LCNS_NO` |

`LCNS_NO`가 공통으로 존재할 때만 HACCP 인증과 행정처분을 연결합니다. 업체명은 자동 결합 키로 사용하지 않습니다.

`record_linkage_audit.csv`는 행정처분·부적합 검사·회수 기록별 허가번호 보유량과 HACCP 명부의 정확 일치 건수를 기록합니다. 상호·주소 유사도 기반 자동 결합은 사용하지 않습니다.

## 해석 제한

이 앱은 위험 예측 모델이나 임의 위험점수를 제공하지 않습니다. “우선 확인 후보”는 실제 허가번호로 연결된 HACCP 인증·행정처분 기록을 보여주는 탐색 결과입니다.

## 공개 배포 전 확인

1. `processed/`에 전처리 파일이 모두 있는지 확인합니다.
2. 공개 가능한 공공데이터만 포함됐는지 검토합니다.
3. GitHub 저장소에 프로젝트를 올린 뒤 Streamlit Community Cloud, Render 등의 호스팅 계정에서 배포합니다.
4. 생성된 공개 URL은 발표자료와 QR 코드에 사용합니다.
